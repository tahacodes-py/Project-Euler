# Project Euler Solutions

My solutions to Project Euler problems, written in C++.

## About

I solve each problem independently first, then debug and refine through careful tracing — no copy-pasted solutions. Each file is self-contained and focused on correctness over premature optimization.

## Problems Solved

| Problem | Title | Description |
|---|---|---|
| [5](./problem5.cpp) | Smallest Multiple | Smallest number evenly divisible by all integers 1–20 |
| [6](./problem6.cpp) | Sum Square Difference | Difference between sum of squares and square of sum (1–100) |
| [7](./problem7.cpp) | 10001st Prime | Find the 10,001st prime number |
| [8](./problem8.cpp) | Largest Product in a Series | Largest product of 13 adjacent digits in a 1000-digit number |

## How to Run

Each solution is a standalone `.cpp` file. Compile and run with:

\`\`\`bash
g++ problemN.cpp -o problemN
./problemN
\`\`\`

(swap `N` for the problem number)
